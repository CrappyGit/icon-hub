# SVGL Icons

A Sine mod for Zen Browser that adds an **SVGL** tab to Zen's icon picker, with
the brand logos from [svgl.app](https://svgl.app). Use them as space and folder
icons. Works alongside Zia's icon tab.

- Search by name or category ("ai", "database", "github"…).
- Logos with light and dark versions use the one that fits your current theme.
- A picked logo is saved to `chrome/sine-mods/svgl-icons/` in your profile, so it
  keeps working offline and if svgl.app changes.

## Install

1. In Sine's settings, turn on **Enable installing JS from unofficial sources**.
2. In Sine's mod list, enter `CrappyGit/svgl-picker` and press **Install**.
3. Restart Zen.

Logos are © their owners; see svgl.app for each brand's usage terms.
